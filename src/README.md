# GoRail 🚆

## AI-Powered Railway Ecosystem

GoRail is a smart railway platform designed for both passengers and railway staff.  
It combines train services, AI assistance, complaint management, multilingual support, and operational workflows into one ecosystem.

---

## ✨ Features

### 👤 Passenger Features

- Train Search & Live Status
- Ticket Booking
- Live Train Tracking
- Station Navigation
- Food Ordering
- AI TC Assistant
- Train Delay Updates
- Complaint Management

### 🏢 Staff ERP Features

- Cleaning Staff Dashboard
- Ticket Checker Dashboard
- Railway Police Dashboard
- Electrical Department Dashboard
- Loco Pilot Controls
- Complaint Assignment System

---

## 🤖 AI Features

- AI Railway Assistant
- Multilingual Support
- Smart Complaint Guidance
- User Navigation Assistance
